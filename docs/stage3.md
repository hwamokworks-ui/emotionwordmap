**A. 인터뷰 준비** 

아래는 질문을 만들 때 쓸 수 있는 4가지 '유형'입니다. 본인의 HMW·근본원인에 맞게 직접 바꿔서 질문을 만드세요.

**내 프로젝트에 맞는 질문 만들고 짝 인터뷰**

① 2단계의 근본원인, ② HMW를 다시 떠올리며 각 유형에 맞는 내 질문을 직접 써보세요.

💡 질문을 그대로 읽기보다, 인터뷰 중에는 '왜 그렇게 하세요?'처럼 자연스럽게 한 번 더 파고드는 게 좋습니다.

💡 실제 사람의 말이 페르소나의 신뢰도를 만듭니다. 인터뷰이가 실제로 한 표현을 최대한 그대로 메모해두세요.

| 유형 | 감정 어휘 확장 및 이모티콘 추천 앱 |
| ----- | ----- |
| **① 현재 방식/습관** | Q) 평소 자신의 감정을 어떻게 정리하거나 표현하시나요? A) 안함. 배우자와의 대화.  |
| **② 최근 실패/불편 경험** | Q) 최근 내 감정을 설명하지 못해서 답답했던 경험이 있나요?  A) 아니요. 늘 솔직하게 말하는 편. 답답한 것 못 참는 편.  |
| **③ 판단 기준** | Q) 감정을 표현할 때 가장 어려운 점은 무엇인가요? (단어 선택, 상대 반응, 솔직함 등)  A) 특별히 어려운 점은 없음. 어릴 때부터 그런 어려움은 없었음. |
| **④ 기존 도구/대안 경험** | Q) 감정 기록 앱, 일기, 심리 테스트 등을 사용해본 경험이 있나요? 왜 계속 사용하거나 그만두셨나요?  A) 일기는 써본 적이 있으나, 일기조차 솔직히 쓰는 게 불편하다. 일기도 결국 누군가 볼 수 있기 때문에 솔직하기 어렵다.  |
| **⑤ 자유 질문** | Q) 내 감정을 더 정확한 단어로 찾고 표현하도록 도와주는 서비스가 있다면 사용할 의향이 있나요? A) 굳이 필요를 느끼지 못함.   |

| 인터뷰한 사람 (익명 가능) |  김홀리 |

**C. AI로 가상 페르소나 후보 3명 만들기**

인터뷰 메모와 1단계 데이터랩 결과를 AI에게 전달해, 서로 다른 특징을 가진 가상 페르소나 3명을 요청합니다.

**④ 유저저니맵 — 페르소나의 하루**

② 에서 만든 페르소나가 서비스를 처음 알게 된 순간부터 습관적으로 쓰게 되기까지의 흐름을 4단계로 그려봅니다.   
단계마다 행동·생각·감정·페인포인트·개선기회를 적으세요.

👉 여기서 찾은 페인포인트·이탈 위험 지점은 다음 시간 MoSCoW 우선순위와 사이트맵을 만들 때 그대로 근거 자료가 됩니다.

| 단계 | 행동 | 생각 | 감정 | 페인포인트 | 개선 기회 |
| ----- | ----- | ----- | ----- | ----- | ----- |
| **① 인지** | 자신의 감정을 표현하려 하지만 적절한 단어가 떠오르지 않아 감정 어휘를 찾아봄 | “기분이 이상한데 뭐라고 표현해야 하지?”“내가 느끼는 감정을 정확하게 설명하고 싶어.” | 답답함 · 막막함 · 호기심 | 감정을 느끼고 있지만 그것을 설명할 감정 어휘가 부족함. 비슷한 감정의 차이를 구분하기 어려움 | 감정 어휘 지도라는 서비스 컨셉을 직관적으로 전달하고, 감정 단어를 몰라도 시작할 수 있다는 점을 강조 |
| **② 첫 사용** | 자신의 감정이나 상황을 입력하거나, 제시된 감정 단어·상황 예시에서 가까운 것을 선택함 | “이런 상황이면 어떤 감정일까?”“내가 느끼는 것도 이 중 하나일까?” | 호기심 · 기대감 · 약간의 혼란 | 첫 화면에서 어떤 감정 단어를 입력해야 할지 막막할 수 있음. 감정을 하나의 단어로 바로 정의하기 어려움 | 감정 입력 \+ 감정 검색 \+ 상황으로 찾기 \+ 감정 단어 예시를 제공해 감정 어휘를 몰라도 탐색을 시작할 수 있게 함 |
| **③ 핵심 사용** | 감정 지도에서 선택한 감정의 위치와 영역을 확인하고, 유사·관련·반대 감정을 탐색하며 비교·제외함. 감정 상세에서 의미와 실제 상황을 확인한 뒤 자신에게 가장 가까운 감정을 선택하고 표현·기록함 | “이 감정과 비슷하지만 조금 다른 것 같아.”“이 상황에서 내가 느낀 감정은 이 단어에 더 가까운 것 같아.”“이제 내가 느낀 감정을 정확하게 설명할 수 있겠다.” | 몰입 · 발견의 즐거움 · 이해 · 안도감 | 비슷한 감정의 미묘한 차이를 판단하기 어려움. 감정 단어의 의미만으로는 자신의 경험과 연결하기 어려움. 찾은 감정을 실제로 어떻게 표현할지도 어려울 수 있음 | 감정 지도 → 영역 탐색 → 감정 관계·거리 → 비교·제외 → 감정 상세의 탐색 흐름을 제공하고, 상세 화면에 감정이 나타나는 상황을 함께 제공. 이후 표현 대상·상황, 표현 문장, 이모티콘, 감정 기록으로 연결 |
| **④ 재방문/습관화** | 이전 감정 기록을 다시 확인하고 감정 변화와 패턴을 살펴봄. 새롭게 발견한 감정 어휘를 도감에 수집하고 탐색·발견 활동을 이어감 | “나는 이런 상황에서 이런 감정을 자주 느끼는구나.”“전에 몰랐던 감정 단어도 알게 됐어.”“다음에는 내 감정을 더 정확하게 표현할 수 있을 것 같아.” | 자기이해 · 성취감 · 친숙함 · 지속적인 관심 | 감정 탐색이 일회성으로 끝날 수 있음. 과거의 감정과 현재의 감정을 연결하거나 자신의 감정 패턴을 파악하기 어려움 | 감정 기록 → 기록 히스토리 → 감정 리포트 → 감정 도감 → 뱃지·업적으로 탐색 경험을 축적하고, 발견한 감정 어휘와 자신의 감정 패턴을 지속적으로 돌아볼 수 있게 함 |
