**① 워킹 스켈레톤의 기본 구조와 사용자 흐름 설계하기**

화면 흐름은 사용자가 화면을 이동하는 동적인 순서를 뜻하며, 4단계 사이트맵(정적 목록)과는 다릅니다. 디자인은 전혀 고려하지 않고, 각 단계에서 필요한 최소한의 화면 요소만 정리합니다.

**프롬프트**

| 4단계에서 완성한 워크시트 파일(MoSCoW 기능표, 사이트맵) 내용을 참고해서, 워킹 스켈레톤 핵심 기능들을 사용하는 가장 단순한 흐름을 단계별로 설명해줘. 각 단계에서 필요한 최소한의 화면 요소(버튼, 입력 필드 등) 및 설명을 언급해줘. UI 디자인은 전혀 고려하지 않아도 돼 |
| :---- |

| 단계 | 화면 요소 (버튼/입력필드 등) | 설명 |
| ----- | ----- | ----- |
| **1\. 감정 탐색 시작** | 감정 입력창, `감정으로 찾기`, `상황으로 찾기`, 추천 감정 어휘, 추천 상황 | 사용자가 정확한 감정 단어를 몰라도 시작할 수 있도록 한다. 직접 감정 어휘를 입력하거나, **추천 어휘·상황** 중 하나를 선택해 탐색을 시작한다. |
| **2\. 감정 후보 탐색** | 입력한 감정/상황, 추천 감정 후보 목록, 후보 선택 버튼, `다시 찾기` | 사용자가 입력한 내용과 관련된 감정 후보를 여러 개 보여준다. 이 단계의 목적은 **정답을 바로 고르는 것이 아니라 탐색할 출발점을 만드는 것**이다. |
| **3\. 감정 지도 미리보기** | 선택한 감정, 감정 지도, 해당 감정이 속한 영역, 주변 감정, `지도에서 자세히 보기` | 선택한 감정이 전체 감정 지도에서 어디에 위치하는지 보여준다. 사용자가 자신의 감정을 하나의 단어가 아니라 **감정의 영역과 위치**로 이해하도록 한다. |
| **4\. 감정 영역 탐색** | 9개 감정 영역, 영역별 감정 어휘, 선택한 영역의 감정 목록 | 분노의 영역, 허탈함의 방, 외로움의 숲, 설렘의 정원, 불안의 바다, 기쁨의 언덕, 슬픔의 강, 부끄러움의 골목, 평온의 호수 등으로 이동해 관련 어휘를 탐색한다. |
| **5\. 감정 관계 탐색** | 유사 감정, 관련 감정, 반대 감정, 감정 간 거리/관계, `이 감정은 아닌 것 같아요`, `다른 영역 보기` | 선택한 감정 주변의 관계를 탐색한다. **비슷하지만 다른 감정, 반대되는 감정, 현재 감정과의 거리**를 비교하면서 자신의 감정을 좁혀간다. 사이트맵의 핵심 탐색 기능이다. |
| **6\. 감정 비교·선택** | 감정 A/B 비교, 감정 의미 차이, 상황 예시, `A가 더 가까워요`, `B가 더 가까워요`, `선택 완료` | 비슷한 감정을 직접 비교하면서 최종적으로 자신이 느낀 감정에 가장 가까운 어휘를 선택한다. 단순 검색이 아니라 **‘발견’하는 과정**을 보여주는 단계다. |
| **7\. 감정 상세 확인** | 감정명, 감정 의미, 특징, 상황 예시, 유사/반대 감정, 표현 문장 추천 | 최종 선택한 감정이 어떤 의미인지 확인하고 자신의 경험과 연결한다. 감정 표현을 위해 **상황별 표현 문장**도 확인한다. |
| **8\. 감정 표현하기** | 표현 대상 선택, 상황 선택, 표현 문장, `문장 복사`, 이모티콘 추천, 캐릭터/감정 표현 요소 | 발견한 감정을 실제로 표현할 수 있도록 연결한다. **표현 문장 → 이모티콘 → 캐릭터**로 이어지며, 감정 어휘를 실제 커뮤니케이션으로 연결하는 부분이다. 초기 아이디어에서도 감정에 맞는 이모티콘 추천이 주요 기능으로 정의되어 있다. |
| **9\. 감정 기록** | 선택한 감정, 상황, 메모 입력창, 날짜/시간, `기록하기` | 발견한 감정을 **감정 \+ 상황 \+ 메모** 형태로 저장한다. 이후 리포트와 히스토리의 데이터가 된다. |
| **10\. 기록 히스토리** | 날짜별 기록 목록, 감정 태그, 검색/필터, 기록 상세 | 지금까지 기록한 감정을 시간순으로 확인한다. 과거의 감정과 상황을 다시 살펴볼 수 있다. |
| **11\. 감정 데이터 시각화** | 기간 선택, 감정 변화 그래프, 감정별 분포, 감정 영역별 분포, 상황별 감정 패턴 | 기록된 데이터를 단순 목록으로 보여주는 것이 아니라 **나의 감정 변화와 패턴을 시각적으로 확인**한다. 워크시트의 감정 리포트에는 기간별 감정 변화와 자주 느끼는 감정/상황 분석이 포함되어 있다. |
| **12\. 감정 리포트** | 감정 변화 요약, 주요 감정, 감정 패턴, `리포트 보기`, `리포트 다운로드` | 일정 기간의 감정 기록을 종합해 나의 감정 변화를 돌아본다. 워크시트에서 **감정 리포트를 수익화 대상으로도 고려**하고 있으므로 워킹 스켈레톤에서도 결과물을 보여주는 것이 좋다. |
| **13\. 감정 도감** | 발견한 감정 어휘 목록, 감정 어휘 상세, `수집`, `나의 어휘` | 탐색하면서 처음 발견한 감정 어휘를 모아본다. 단순 기록이 아니라 **새로운 감정 어휘를 하나씩 발견하고 쌓아가는 경험**을 만든다. |
| **14\. 뱃지·업적** | 획득 뱃지, 업적 조건, 진행률, `획득한 뱃지 보기` | 감정 탐색·기록·어휘 수집 등의 활동에 따라 보상을 제공한다. 예를 들어 `감정 10개 발견`, `첫 기록`, `7일 기록`처럼 탐색과 기록을 지속하게 만드는 장치다. 워크시트에서도 **감정 도감·캐릭터·뱃지·수집·성장 요소**가 지속 사용을 위한 기능으로 제시되어 있다. |

| :---- |

| 항목 | 내용 |
| :---- | :---- |
| 주요 목표 | 사용자가 **자신의 감정을 정확한 단어로 찾고, 그 감정을 이해·표현·기록하는 전체 경험**을 실제로 따라가 볼 수 있도록 구현한다. 특히 단순한 감정 기록 앱과 달리, **감정 어휘를 몰라도 탐색을 시작하고 → 감정 간 관계와 차이를 비교하며 → 자신에게 맞는 감정 어휘를 발견하는 과정**이 핵심 가치로 작동하는지 검증한다. 이는 최종 페르소나인 **혼자 생각하고 자신을 돌아보며, 복잡한 감정을 정확한 단어로 표현하고 싶어 하는 자기이해형 사용자**의 문제를 해결하기 위한 것이다. |
| ① 감정·상황 기반 탐색 및 어휘 추천 | 페르소나는 감정이 복잡하거나 여러 감정이 섞였을 때 적절한 단어를 찾기 어렵다. 따라서 정확한 감정 단어를 모르는 상태에서도 감정이나 상황을 입력하고 추천 어휘를 통해 탐색을 시작할 수 있어야 한다. |
| ② 감정 지도 및 감정 관계 탐색 | 단순한 감정 기록만으로는 자신의 감정을 충분히 이해하기 어렵다는 페인포인트가 있다. 따라서 감정의 위치, 영역, 유사·관련·반대 감정, 감정 간 거리와 관계를 탐색하면서 자신의 감정을 구체적으로 좁혀갈 수 있어야 한다. |
| ③ 감정 상세·표현 및 이모티콘/캐릭터 | 페르소나의 최종 목표는 단순히 감정을 기록하는 것이 아니라 자신의 감정을 정확한 단어로 이해하고 표현하는 것이다. 따라서 선택한 감정의 의미와 상황 예시를 확인하고, 표현 문장과 이모티콘·캐릭터 등 실제 표현 수단으로 연결되어야 한다. |
| ④ 감정 기록·시각화·리포트·도감/뱃지 | 감정 탐색이 일회성으로 끝나지 않도록 발견한 감정을 기록하고, 기록 데이터를 시각화하여 자신의 감정 패턴을 돌아볼 수 있어야 한다. 또한 감정 리포트, 감정 도감, 뱃지·업적을 통해 탐색과 기록이 축적되는 경험까지 보여준다. |
| 핵심 사용자 흐름 | 감정/상황 입력 → 추천 감정 어휘 탐색 → 감정 지도에서 위치·영역 확인 → 유사·관련·반대 감정 및 거리 비교 → 나에게 가장 가까운 감정 선택 → 감정 상세·상황 예시 확인 → 표현 문장·이모티콘/캐릭터로 표현 → 감정 \+ 상황 \+ 메모 기록 → 기록 히스토리 및 감정 데이터 시각화 → 감정 리포트 확인/다운로드 → 발견한 감정 어휘를 도감에 수집하고 뱃지·업적 획득  |

# **④ 페르소나 검증**

완성된 화면 시안이 3단계에서 만든 페르소나의 문제를 실제로 해결하는지 다시 검토합니다.

**프롬프트** 

| 3단계에서 작성한 페르소나 워크시트 파일을 다시 첨부해줘. 방금 완성한 화면 흐름과 시안을 그 페르소나의 목표·페인포인트 관점에서 다시 검토해줘. 이 화면들이 페르소나의 문제를 실제로 해결하는지, 빠뜨린 페인포인트는 없는지 짚어줘. |
| :---- |

| 페르소나 검증 항목 | 화면에 반영됐는가 (O/X) | 보완 필요 사항 |
| ----- | :---: | ----- |
| 목표 — "지금 느끼는 감정을 정확히 알고 나에게 맞는 단어로 표현하고 싶다" | O | find→map 흐름 전체가 목표를 지원. 없음 |
| 페인포인트 — 여러 감정이 섞였을 때 단어가 모호함 | O | 지도의 근접 감정(거리 %)·반의어·조금 다른 감정 chip으로 비교·제외 가능 |
| 페인포인트 — 단순 좋음/나쁨 기록만으로는 부족함 | O | 145단어 세분화 \+ 강도(intensity) 바 \+ 예문으로 해결됨 |

| 저니맵 ①인지 — 감정 어휘 부족, 비슷한 감정 구분 어려움 | O | "감정 찾기에서 감정을 찾거나 지도에서 클릭해 발견" 안내, 흐린 노드도 클릭 가능하게 되어 있어 단어를 몰라도 진입 가능 |
